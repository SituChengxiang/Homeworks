# 对称操作 · 反轴 n̄ 与正四面体的 24 个操作

黄昆《固体物理》里"晶体的对称性"那一节的可视化，和晶胞那三页**分开成独立目录**：
这一页只管对称元素与点群，不讲晶胞、不讲堆积。

成品只有一个文件，双击即开，不联网、不用起服务器：

- **`symmetry-operations.html`** —— 交这个（约 550 KB，three.js 已内联）

老师提的两件事都在这一页里，各一段分步演示：

1. **反轴**：`3̄ = 3 + i`、`4̄ = 4 + i`，那么 `6̄ = ?`
   → 算出来 **`6̄ = 3/m`**（一根 3 次轴 + 一个垂直于它的镜面，群记号 C3h）。
   它里面**根本没有 6 次操作**：转 60° 再反演，偶数次幂回到真旋转时只剩 120°/240°，奇数次幂给出对水平面的反映。
   顺带把 `1̄ = i`、`2̄ = m`、`4̄` 独立（= S4，既无 i 也无镜面）一并画出来。
2. **正四面体的 24 个对称操作（Td）**：`E + 8C₃ + 3C₂ + 6S₄ + 6σd = 24`，
   按"棱向 / 体对角线 / 对角面"写出对称元素就是国际记号 **`4̄3m`** —— 也正是金刚石、闪锌矿的点群。

## 操作 · 反轴那一段

左边「讲哪一段」选 **反轴 n̄**，然后：

- **分步讲解**（8 步）：定义 → `1̄` → `2̄` → `3̄` → `4̄` → **`6̄ = ?`** → 一步一步施加 → 为什么晶体学只有这五种。
  `←/→` 换步骤，`空格` 播放/暂停，关掉开关回到自由查看。
- **选择反轴**：`1̄…6` 六个按钮（`5̄` 标了"非晶体学"，画它是为了说明 5 次轴填不满格子）。键盘 `1…6` 同效。
- **施加次数 k**：只在打开"一步一步施加"图层时起作用，拖一下看第 k 次落在哪个等效点、第 |G| 次回到 P。
- 图层：原始基元（带右手系三面角）、全部等效点、编号、配对关系、水平镜面 m⊥、对称中心 i。
  **镜面片和 i 的高亮只有在群里真的有这个元素时才画**——所以 `4̄` 那一步画面干净，正是它"既没有 i 也没有 m⊥"的证据。
- 右侧面板：群的阶、真旋转最高几次、有没有 i / m⊥、等价记号，以及一张"幂次 → 做了什么 → P 落到哪 → det"的表。

看的时候盯两件事：

1. **等效点有几个**（一般位置的点，轨道大小就等于群的阶）：`1̄,2̄` → 2 个，`4̄` → 4 个，`3̄,6` → 6 个。
2. **这些点怎么配对**：`3̄` 的 6 个点两两关于**原点**对称（3 对虚线穿过中心）→ 群里有 i；
   `6̄` 的 6 个点两两关于**水平面**对称 → 群里有 m⊥ 而没有 i。这就是 `3/m` 这个答案的图形版本。

那个红绿蓝小三面角是手性指示器：`det = −1` 的操作做完它变成左手系。反轴、镜面这类操作光看位置看不出来"翻了面"，看标架就看得出来。

## 操作 · 四面体那一段

选 **四面体 Td**：

- **分步讲解**（8 步）：把四面体放进立方体 → 12 个真旋转（T 群）→ 6 个 σd → 3 条 `4̄` 轴上的 6 个 S₄ → 合计 24 个数出 `4̄3m` → 顶点置换 = S₄ → 手性 → 与 Oh 48 个操作的关系。
- **24 个操作**的按钮按共轭类分组（E / 8C₃ / 3C₂ / 6S₄ / 6σd），点一个四面体就照着那个矩阵变形：
  真旋转走轴角插值；非真操作先转再"压扁到镜面上、从另一面出来"，终点严格等于该矩阵（`test/verify.js` 逐条守住这件事）。
  `[ / ]` 或"上/下一个"换操作，"依次播放 24 个"过一遍，"四面体复位"回到 E。
- 图层：参考立方框、四个面着色、六条棱、顶点球与编号、体心手性三面角、变形前的原位置、`3 条 4̄ 轴`、`4 条 3 次轴`、`6 个 σd 镜面`。
  后三个图层一开，`4̄3m` 的三个位置就全部指在图上。
- 右侧面板：这个操作的共轭类、真/非真、对称元素方向、转动反映角、**顶点置换**（`1243` 这种写法）与奇偶、3×3 矩阵，
  外加一张五个共轭类 + 合计 24 的表。

四面体的 4 个顶点取的是立方体 8 个角里互不相邻的那 4 个（坐标乘积 = +1）。
这样三条棱向 ⟨100⟩ 直接就是 `4̄` 轴、4 条体对角线 ⟨111⟩ 就是 3 次轴、6 个 {110} 对角面就是 σd，
而且这套隔角顶点正是金刚石 / 闪锌矿里一个原子的 4 个最近邻 —— 和上层 `diamond-zincblende.html` 是同一件事。

## 设计说明

- **结论必须由矩阵算出来**。`6̄ = 3/m` 不是写在文案里的一句话：`barGroup(6)` 把 6 个元素闭包出来，
  数出真旋转最高 3 次、含 m⊥、不含 i，再由这些事实拼出等价记号；`test/verify.js` 进一步要求
  `⟨6̄⟩` 与 `⟨3 次轴, 水平镜面⟩` 是**同一个集合**，`⟨3̄⟩` 与 `⟨3 次轴, i⟩` 是同一个集合，`2̄` 的矩阵**逐元素等于**水平镜面矩阵。
- **算术里不做提前四舍五入**。最初 `mul()` 把每个元素 round 到 1e-6，于是 `0.866025² + 0.5² ≠ 1`，
  连乘几次后矩阵不再是正交阵，幂永远回不到单位阵——群的阶直接算错。现在取整只出现在显示和 keying 里。
- **正交矩阵分解成"转轴 + 转角"**：det = +1 取轴角；det = −1 唯一写成"对某个过原点的平面反映 + 绕同一法线转 θ"
  （法线就是 −1 本征向量）。这样 `4̄`、`S₄`、`σd` 能用同一条动画路径演，且 t = 1 时严格回到原矩阵。
- **不该画的不能画**：`3̄` 那一步没有水平镜面，所以画面里就没有圆片；`4̄` 既无 i 也无 m⊥，两个高亮都不出现。
  学生靠"少了什么"来记这几个反轴的区别，比看文字有效。
- **24 = |S₄|** 用顶点置换现场演示：24 个操作给出 24 个置换，一个不多一个不少；其中 12 个真旋转是偶置换 = A₄ = T 群。
  再往外一步：Oh 的 48 个带符号置换里，24 个保住这套四面体（就是 Td），24 个把它换成互补的第二套 —— 金刚石那两套 FCC。
