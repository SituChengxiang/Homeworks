### 二、MATLAB的关键概念（结合真题考点）

#### 1. 变量命名规则（23-24期末 Q1）

- **合法**：字母开头，含字母/数字/下划线，如 `xyz_3`, `x3Yz`
- **非法**：含特殊字符（如 `-`）、数字开头，如 `abc-3`
- **考试陷阱**：MATLAB 区分大小写，`ABC` 与 `abc` 是不同变量

#### 2. 数组 vs 矩阵运算的核心区别

```matlab
a = [1,2; 3,4]; b = [5,6; 7,8];
a.*b   % 逐元素乘 = [5,12; 21,32]
a*b    % 矩阵乘 = [1*5+2*7, 1*6+2*8; 3*5+4*7, 3*6+4*8] = [19,22; 43,50]
a\b    % 解 ax=b，等价于 inv(a)*b
```

- 23-24期末 Q2 考查：`a=2:2:8`（[2,4,6,8]），`b=2:5`（[2,3,4,5]）  
  - `a'*b` 合法：4×1 乘 1×4 → 4×4 矩阵  
  - `a.*b` 合法：同维数组逐元素乘  
  - `a*b` **非法**：1×4 乘 1×4 不满足内维相等  
  - `a-b` 合法：同维数组逐元素减

#### 3. 匿名函数的精确写法（！）

- **23-24期末 Q3**：`f(x,y) = x^3 + 2*y*ln(x)` →  
  `f = @(x,y) x.^3 + 2.*y.*log(x)`  
  （注意：`^`→`.^`, `*`→`.*`, `ln`→`log`）
- **24-25期末 Q5**：`f(x) = exp(-αx²)` →  
  `f = @(x) exp(-alpha.*x.^2)`  
  （注意：`α` 需提前定义，`x²`→`x.^2`）

#### 4. 有效数字与精度（24-25期末 Q7; 25-26期中 Q6）

- **规则**：从第一个非零数字起，到最末一位数字止
- **真题**：
  - 3.141592 → 3.14：**3位**有效数字
  - 1,000,000 → 999,996：**6位**有效数字（999996 与 1000000 仅差 4，相对误差小）
  - 187.9325（5位）→ **187.93**
  - 0.03785551（5位）→ **0.037856**（四舍五入进位）
  - 8.000033（5位）→ **8.0000**（末尾0不能省）

### 二、关键原理与MATLAB实现（！）

#### 1. 非线性方程求根（23-24期末 Q6/Q8；24-25期末 Q6）

- **牛顿法迭代公式**（手工必须会，MATLAB用`fsolve`）：
  $$
  x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)}
  $$
- **真题匹配**：
  - 23-24期末：求$\sqrt{2}$ → $f(x)=x^2-2$，迭代公式 $x_{n+1} = \dfrac{1}{2}(x_n + \dfrac{2}{x_n})$
  - 24-25期末：求$x^2-x-1=0$ → 迭代公式 $x_{n+1} = x_n - \dfrac{x_n^2-x_n-1}{2x_n-1}$
- **MATLAB实现**：

  ```matlab
  % 求 sqrt(2)
  f = @(x) x.^2 - 2;
  df = @(x) 2.*x;
  newton = @(x) x - f(x)./df(x);
  x0 = 1; 
  for k = 1:5
      x0 = newton(x0);
  end
  % 或直接用fzero
  root = fzero(@(x) x.^2-2, 1);
  ```

#### 2. 常微分方程（23-24期末 Q10-11；24-25期末 Q3）

- **Heun方法（RK2）公式**（23-24期末 Q3）：
  $$
  \begin{aligned}
  k_1 &= f(x_n, y_n) \\
  k_2 &= f(x_n + h, y_n + hk_1) \\
  y_{n+1} &= y_n + \dfrac{h}{2}(k_1 + k_2)
  \end{aligned}
  $$
- **真题匹配**：23-24期末 Q3：$y' = 2x^2y$, $y(0)=1$, $h=0.5$, 求$y(1.0)$
- **MATLAB实现**：

  ```matlab
  % 手动实现Heun法
  f = @(x,y) 2.*x.^2.*y;
  h = 0.5; x = 0:h:1; y = zeros(size(x)); y(1) = 1;
  for n = 1:length(x)-1
      k1 = f(x(n), y(n));
      k2 = f(x(n)+h, y(n)+h*k1);
      y(n+1) = y(n) + h*(k1+k2)/2;
  end
  % 或用ode45
  odefun = @(x,y) 2*x.^2.*y;
  [x_ode, y_ode] = ode45(odefun, [0,1], 1);
  ```

#### 3. 数值积分（23-24期末 Q6/Q14；24-25期末 Q6）

- **Simpson公式**：
  $$
  \int_a^b f(x)dx \approx \dfrac{h}{3}[f(x_0) + 4f(x_1) + 2f(x_2) + \cdots + 4f(x_{n-1}) + f(x_n)]
  $$
  其中$n$为偶数，$h=(b-a)/n$
- **误差项**（23-24期末 Q14；24-25期末 Q14）：
  $$
  E = -\dfrac{(b-a)}{180}h^4 f^{(4)}(\xi), \quad \xi \in [a,b]
  $$
  代数精度为3
- **真题匹配**：23-24期末 Q6：7个节点（$n=6$区间）用复合Simpson
- **MATLAB实现**：

  ```matlab
  % 手动实现复合Simpson
  f = @(x) sin(2*x).^4;
  a = 0; b = 6*pi; n = 6; % 7个点
  h = (b-a)/n; x = a:h:b; y = f(x);
  S = h/3 * (y(1) + y(end) + 4*sum(y(2:2:end-1)) + 2*sum(y(3:2:end-2)));
  % 或用integral
  I = integral(f, 0, 6*pi);
  ```

#### 4. 线性方程组（23-24期末 Q9/Q1；24-25期末 Q9/Q11）

- **LU分解**（23-24期末 Q9）：

  ```matlab
  A = [1,2; -2,3];
  [L,U] = lu(A); % MATLAB的lu返回置换矩阵P，需注意
  % 手动计算：U = [1,2; 0,7]
  ```

- **Gauss-Seidel迭代**（24-25期末 Q11）：

  ```matlab

  b = [6;25;-11];

  for k = 1:3
      x(1) = (b(1) + x(2) - 2*x(3))/10;
      x(2) = (b(2) + x(1) + x(3))/11;

      fprintf('k=%d: [%f, %f, %f]\n', k, x);
  ```

### 四、第二部分的操作性考点清单（考前1小时速记）

1. **函数句柄写法**：
   - 单变量：`f = @(x) exp(-x.^2)`
   - 双变量：`f = @(x,y) x.^2 + y.*sin(x)`

2. **积分命令选择**：
   - 常规问题用`integral`（自适应，精度高）
   - 古老代码可能用`quadl`（Lobatto规则）

   - 非刚性问题首选`ode45`（自适应步长，精度好）

4. **根查找注意事项**：
   - `fzero`要求函数在区间端点符号相反
   - 多根问题：尝试不同初始值`x0`
   - 复根问题：需用其他方法（如`roots`求多项式根）

5. **矩阵分解命令**：
   - LU分解：`[L,U,P] = lu(A)`（返回置换矩阵P）
   - 特征值：`[V,D] = eig(A)`，`D=diag(eig(A))`

## 第三部分 数值计算预备知识复习

### 一、必须背熟的核心概念（填空/简答题高频）

#### 1. 有效数字规则（★★★ 三份试卷均有考查）

- **定义**：从第一个非零数字起，到最末一位数字止的所有数字
- **判断规则**：
  - 1000000 与 999996 有 **6位** 有效数字（相对误差 $4 \times 10^{-6}$）
  - 3.141592 → 3.14：**3位** 有效数字
  - 0.0012345（5位）→ **0.0012345**（前导0不算）
- **四舍五入原则**（25-26期中 Q6）：
  - 187.9325（5位）→ **187.93**
  - 0.03785551（5位）→ **0.037856**（第六位5进位）
  - 8.000033（5位）→ **8.0000**（末尾0不能省）

#### 2. 浮点运算误差来源（23-24期末 Q1；25-26期中 Q3）

- **舍入误差**（Rounding error）：
  - 有限位数表示实数导致
  - 例：$\sqrt{2} \approx 1.41421356$ 只能存储有限位
- **截断误差**（Truncation error）：
  - 用近似公式代替精确公式导致
  - 例：Taylor展开截断、差分公式替代导数
- **传播误差**（Propagation error）：
  - 误差在计算过程中的累积和放大
  - 25-26期中 Q3：递推关系 $y_n = 10y_{n-1}$ 使初始误差放大 $10^n$ 倍

#### 3. 应当避免的数值运算（23-24期末 Q4；25-26期中 Q3）

| **危险操作** | **后果** | **替代方案** | **真题体现** |
|--------------|----------|--------------|--------------|
| 大数减小数 | 有效数字严重损失 | 代数变换 | 23-24期末 Q4 |
| 大步长微分 | 截断误差主导 | 最优步长选择 | 23-24期末 Q4 |
| 递推放大 | 误差指数级增长 | 反向递推/稳定算法 | 25-26期中 Q3 |
| 病态矩阵求逆 | 解严重失真 | 迭代法/正则化 | 23-24期末 Q1 |

#### 4. 算法数值稳定性（25-26期中 Q3）

- **绝对稳定**：对固定步长 $h$，当 $n \to \infty$ 时误差不增长
- **相对稳定**：误差增长速度不快于解本身的增长速度
- **判定方法**（25-26期中 Q3）：
  - **递推关系** $y_n = f(y_{n-1})$：若 $|\dfrac{\partial f}{\partial y}| > 1$，不稳定
  - **差分格式**：对 $y' = \lambda y$ ($\lambda < 0$)，欧拉法要求 $|1 + h\lambda| < 1$

### 二、关键公式与推导（计算题核心）

#### 1. 最优步长计算（23-24期末 Q4；24-25期末无，但25-26期中隐含）

- **中心差分公式**：
  $$
  f'(x) \approx \dfrac{f(x+h) - f(x-h)}{2h}
  $$
- **误差分析**：
  - 截断误差（Taylor展开）：$O(h^2)$
    $$
    E_T = \dfrac{h^2}{6}f'''(\xi)
    $$
  - 舍入误差：设函数计算精度为 $\varepsilon$，则
    $$
    E_R \approx \dfrac{2\varepsilon}{2h} = \dfrac{\varepsilon}{h}
    $$
- **总误差极小化**：
  $$
  E_{\text{total}} = |E_T| + |E_R| \approx \dfrac{Mh^2}{6} + \dfrac{\varepsilon}{h}
  $$
  令 $\dfrac{dE_{\text{total}}}{dh} = 0$：
  $$
  \dfrac{Mh}{3} - \dfrac{\varepsilon}{h^2} = 0 \quad \Rightarrow \quad h_{\text{opt}} = \sqrt[3]{\dfrac{3\varepsilon}{M}}
  $$
  **23-24期末 Q4真题**：$f(x) = \sin x$，$\varepsilon = 0.5 \times 10^{-8}$
  - $f'''(x) = -\cos x$，取 $M = \max|\cos x| = 1$
  - $h_{\text{opt}} = \sqrt[3]{\dfrac{3 \times 0.5 \times 10^{-8}}{1}} \approx \sqrt[3]{1.5 \times 10^{-8}} \approx 0.00247$

#### 2. 误差传播规律（25-26期中 Q3）

- **线性递推** $y_n = a y_{n-1}$：
  - 初始误差 $\delta_0$ 传播到第 $n$ 步：$\delta_n = a^n \delta_0$
  - 稳定条件：$|a| < 1$
- **25-26期中 Q3真题**：$y_n = 10y_{n-1}$，$y_0 = \sqrt{2} \approx 1.41$（精确值 1.41421356...）
  - 初始误差：$\delta_0 = 1.41421356 - 1.41 = 0.00421356$
  - 第10步误差：$\delta_{10} = 10^{10} \times 0.00421356 \approx 4.21356 \times 10^7$
  - **结论**：计算过程**不稳定**，误差指数级放大

### 五、常微分方程的求解（计算题）

#### 1. 常微分方程的求解核心方法对比表（必背！）

| **方法** | **公式** | **局部截断误差** | **全局截断误差** | **真题出处** |
|----------|----------|-------------------|-------------------|--------------|
| 欧拉法 | $y_{n+1} = y_n + hf(x_n,y_n)$ | $O(h^2)$ | $O(h)$ | 23-24期末 Q11 |
| 隐式欧拉 | $y_{n+1} = y_n + hf(x_{n+1},y_{n+1})$ | $O(h^2)$ | $O(h)$ | 23-24期末 Q11 |
| Heun法 (RK2) | $y_{n+1} = y_n + \dfrac{h}{2}(k_1+k_2)$<br>$k_1 = f(x_n,y_n)$<br>$k_2 = f(x_n+h,y_n+hk_1)$ | $O(h^3)$ | $O(h^2)$ | 23-24期末 Q3 |
| 4阶RK法 | $y_{n+1} = y_n + \dfrac{h}{6}(k_1+2k_2+2k_3+k_4)$ | $O(h^5)$ | $O(h^4)$ | 24-25期末 Q3 |

#### 2. 常微分方程的求解关键原理与真题匹配

##### 2.1 Heun法（23-24期末 Q3）

- **23-24期末 Q3真题**：用Heun方法求解$y' = 2x^2y$，$y(0)=1$，$h=0.5$，计算$y(1.0)$
  - 公式：
    $$
    \begin{aligned}
    k_1 &= f(x_n,y_n) = 2x_n^2y_n \\
    k_2 &= f(x_n+h,y_n+hk_1) = 2(x_n+h)^2(y_n+hk_1) \\
    y_{n+1} &= y_n + \dfrac{h}{2}(k_1+k_2)
    \end{aligned}
    $$
  - 计算步骤：
    - $n=0$: $x_0=0$, $y_0=1$
      $k_1 = 2\times0^2\times1 = 0$
      $k_2 = 2\times(0+0.5)^2\times(1+0.5\times0) = 0.5$
      $y_1 = 1 + \dfrac{0.5}{2}(0+0.5) = 1.125$
    - $n=1$: $x_1=0.5$, $y_1=1.125$
      $k_1 = 2\times0.5^2\times1.125 = 0.5625$
      $k_2 = 2\times(0.5+0.5)^2\times(1.125+0.5\times0.5625) = 2\times1^2\times1.40625 = 2.8125$
      $y_2 = 1.125 + \dfrac{0.5}{2}(0.5625+2.8125) = 1.96875 \approx 1.969$

##### 2.2 二阶RK法（24-25期末 Q3）

- **24-25期末 Q3真题**：用二阶龙格库塔方法求解$y' = x^3y$, $y(0)=1$, $0\leq x\leq 1$, $h=0.2$
  - 一般二阶RK公式：
    $$
    \begin{aligned}
    k_1 &= f(x_n,y_n) \\
    k_2 &= f(x_n+\alpha h, y_n+\beta hk_1) \\
    y_{n+1} &= y_n + h[(1-\dfrac{1}{2\alpha})k_1 + \dfrac{1}{2\alpha}k_2]
    \end{aligned}
    $$
  - Heun法是特例：$\alpha=1$, $\beta=1$, $y_{n+1} = y_n + \dfrac{h}{2}(k_1+k_2)$

#### 3. 常微分方程的求解真题匹配训练

**23-24期末 Q3真题**  
> 用休恩方法求解初值问题：
> $$\begin{cases}
y' = 2x^2y, & x \geq 0 \\
y(0) = 1
\end{cases}$$
> 以$h=1/2$为步长计算$y(1.0)$的近似值，计算结果保留到小数点后3位。  
> **解**：  
>
> 1. 公式：
>   $$\begin{aligned}
k_1 &= f(x_n,y_n) = 2x_n^2y_n \\
k_2 &= f(x_n+h,y_n+hk_1) = 2(x_n+h)^2(y_n+hk_1) \\
y_{n+1} &= y_n + \dfrac{h}{2}(k_1+k_2)
\end{aligned}$$
> 2. 计算过程：
>    - $n=0$: $x_0=0$, $y_0=1$
>      $k_1 = 2\times0^2\times1 = 0$
>      $k_2 = 2\times(0+0.5)^2\times(1+0.5\times0) = 2\times0.25\times1 = 0.5$
>      $y_1 = 1 + \dfrac{0.5}{2}(0+0.5) = 1.125$
>    - $n=1$: $x_1=0.5$, $y_1=1.125$
>      $k_1 = 2\times0.5^2\times1.125 = 2\times0.25\times1.125 = 0.5625$
>      $k_2 = 2\times(0.5+0.5)^2\times(1.125+0.5\times0.5625) = 2\times1^2\times(1.125+0.28125) = 2\times1.40625 = 2.8125$
>      $y_2 = 1.125 + \dfrac{0.5}{2}(0.5625+2.8125) = 1.125 + 0.25\times3.375 = 1.125 + 0.84375 = 1.96875 \approx 1.969$
> **答案**：$y(1.0) \approx 1.969$

### 六、第四部分操作性考点清单（考前1小时速记）

#### 1. 非线性方程的求根

- 牛顿法迭代公式：$x_{k+1} = x_k - \dfrac{f(x_k)}{f'(x_k)}$
- 二分法条件：$f(a)f(b)<0$
- 收敛阶：牛顿法2阶，割线法1.618阶，二分法1阶

#### 2. 线性方程组

- LU分解：$A=LU$，$L$单位下三角，$U$上三角
- 严格对角占优：$|a_{ii}| > \sum_{j\neq i}|a_{ij}|$
- Gauss-Seidel迭代公式：用新值立即更新：
  $$
  x_i^{(k+1)} = \dfrac{1}{a_{ii}}(b_i - \sum_{j<i}a_{ij}x_j^{(k+1)} - \sum_{j>i}a_{ij}x_j^{(k)})
  $$

#### 3. 插值与拟合

- 牛顿插值：$N_n(x) = f[x_0] + f[x_0,x_1](x-x_0) + \cdots$
- 拉格朗日误差：$R_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^n (x-x_i)$
- 差商递推：$f[x_i,\ldots,x_{i+k}] = \dfrac{f[x_{i+1},\ldots,x_{i+k}] - f[x_i,\ldots,x_{i+k-1}]}{x_{i+k}-x_i}$

#### 4. 数值积分与微分

- Simpson误差：$-\dfrac{(b-a)h^4}{180}f^{(4)}(\xi)$，代数精度3
- 最优步长：$h_{\text{opt}} = \sqrt[3]{\dfrac{3\varepsilon}{M}}$
- 5点导数公式：
  $$
  f'(x) \approx \dfrac{-f(x+2h)+8f(x+h)-8f(x-h)+f(x-2h)}{12h}
  $$

#### 5. 常微分方程

- Heun法：
  $$
  \begin{aligned}
  k_1 &= f(x_n,y_n) \\
  k_2 &= f(x_n+h,y_n+hk_1) \\
  y_{n+1} &= y_n + \dfrac{h}{2}(k_1+k_2)
  \end{aligned}
  $$
- 4阶RK法：
  $$
  \begin{aligned}
  k_1 &= f(x_n,y_n) \\
  k_2 &= f(x_n+\dfrac{h}{2},y_n+\dfrac{h}{2}k_1) \\
  k_3 &= f(x_n+\dfrac{h}{2},y_n+\dfrac{h}{2}k_2) \\
  k_4 &= f(x_n+h,y_n+hk_3) \\
  y_{n+1} &= y_n + \dfrac{h}{6}(k_1+2k_2+2k_3+k_4)
  \end{aligned}
  $$

## 七、助教硬核建议
