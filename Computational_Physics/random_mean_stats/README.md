# 随机数统计作业：三个均匀随机数平均值的分布

## 1. 题目

1. 在 [0, 1] 上生成 3 个随机数，求算术平均 x̄；
2. 重复 N = 1000 次，记录 x_i（i = 1, 2, …, N）；
3. 以箱宽 0.1 对 x_i 做统计，记录每箱计数，画散点图；
4. 用分箱数据做 Lagrange 多项式插值，记录多项式参数，并把曲线画进上图；
5. 用
   \[
   f(x)=\frac{A}{\sigma\sqrt{2\pi}}\exp\!\left[-\frac{(x-m)^2}{2\sigma^2}\right]
   \]
   拟合第 3 步的结果，记录 m、σ 与拟合曲线。

题目原式里写的是 \(N\)，但第 3 步的纵轴是**每箱计数**，箱宽 Δx = 0.1。
一个箱子的期望计数是

\[
\langle \text{count}_i\rangle = N\int_{x_i-\Delta x/2}^{x_i+\Delta x/2} f_{\text{pdf}}(x)\,dx
\approx N\,\Delta x\, f_{\text{pdf}}(x_i),
\]

所以计数尺度的幅度应为 \(A=N\Delta x=100\)，而不是 \(N=1000\)。第 5 步
把三种口径都算出来对照，主拟合采用 \(A=N\Delta x\)。

## 2. 理论值

x̄ 是 3 个独立 U(0,1) 随机数的平均：

\[
E[\bar x]=\frac12,\qquad \operatorname{Var}[\bar x]=\frac{1}{12\cdot 3}=\frac1{36},
\qquad \sigma_{\bar x}=\frac16\approx 0.166667.
\]

三个均匀数之和服从 Irwin–Hall 分布，x̄ 是它的缩放版本。密度为分段二次函数：

\[
f_{\bar x}(x)=
\begin{cases}
\dfrac{3}{2}(3x)^2, & 0\le x\le \tfrac13,\\[4pt]
\dfrac{3}{2}\left[-2(3x)^2+6(3x)-3\right], & \tfrac13\le x\le \tfrac23,\\[4pt]
\dfrac{3}{2}(3-3x)^2, & \tfrac23\le x\le 1.
\end{cases}
\]

它在 0 和 1 处为零，不是正态分布；第 2 步用它的 CDF 给出每箱的精确期望计数，
作为分箱统计的标准答案。正态拟合只是近似，这一点在第 5 步会量化。

## 3. 模块划分

| # | 文件 | 职责 |
|---|---|---|
| 0 | `include/config.h` | N=1000、每个样本 3 个均匀数、固定种子 |
| 1 | `rng.h/.c` | C89 `rand()` 的封装，两次调用拼出约 30 位精度；种子固定后本机可复现 |
| 2 | `sampling.h/.c` | k 个均匀数取平均；只依赖 `rng.c` |
| 3 | `stats.h/.c` | 均值、样本标准差、极值 |
| 4 | `histogram.h/.c` | 等宽分箱；最后一箱右端点闭合，越界样本单独计数 |
| 5 | `irwin_hall.h/.c` | 精确 pdf / CDF，给出每箱期望计数 |
| 6 | `lagrange.h/.c` | Lagrange 插值：展开升幂系数 + 直接基函数求值 |
| 7 | `gauss_fit.h/.c` | Levenberg–Marquardt 拟合高斯，解析雅可比，幅度可固定/自由 |
| 8 | `main.c` | 调度五步、打印验证表、导出数据 |
| 9 | `plot.py` | 分步图：散点、插值、拟合 |
| 10 | `plot_final.py` | 交付图：三要素叠加 + 拟合残差面板 |
| 11 | `verify.h/.c` | **代入式核对**：读回 `data/` 里的数字验恒等式（14 项） |
| 12 | `test/selfcheck.c` | C 单元自检（21 项，直接调用被测模块） |
| 13 | `test/verify.py` | Python 独立交叉核对（17 项，比对 C 的输出文件） |
| 14 | `make_single_source.py` | 把上面这些模块拼成单文件版 `random_mean_stats_single.c`（生成物，不要手改） |

解耦要点：`rng.c` 不知道什么是样本平均，`sampling.c` 不知道分箱，
`histogram.c` 不知道分布，`lagrange.c` 与 `gauss_fit.c` 都只拿到
`(x_i, y_i)` 数组。换分布只动 `sampling.c`，换箱宽只动 `config.h` 与
`main.c` 里的分箱参数。

## 4. 构建与运行

严格 C89：

```sh
sh build.sh          # gcc -std=c89 -pedantic-errors -Wall -Wextra -O2
```

一条龙（编译 → 采样/分箱/插值/拟合 → 最终图）：

```sh
sh run.sh
```

分步：

```sh
./build/random_mean_stats data              # 默认 N=1000, seed=20261024
./build/random_mean_stats data -n 100000    # 加大样本量
./build/random_mean_stats data --seed 7     # 换种子

python3 plot.py data                        # 第 3 步散点
python3 plot.py data --lagrange             # 第 4 步加插值
python3 plot.py data --gauss                # 第 5 步加拟合
python3 plot_final.py data                  # 交付图 + 残差
```

只依赖标准 C 库与 `-lm`；Python 端只要 numpy / matplotlib，不需要 scipy。

## 5. 验证结果

以下数字全部来自 `seed = 20261024, N = 1000` 的一次运行。

### 5.1 采样层

| 检查 | 实测 | 理论 / 判据 |
|---|---|---|
| 同种子重跑 | 逐字节一致 | 可复现 |
| 样本均值 | 0.506059 | 0.5，标准误 0.005270，z = +1.15 |
| 样本标准差 | 0.174313 | 1/6 = 0.166667，相对偏差 +4.59%（2.05 倍抽样标准差） |
| 取值范围 | [0.046089, 0.968539] | 落在 [0, 1] |
| 原始均匀数（30000 次） | 均值 0.500659，方差 0.082823 | 0.5、1/12 = 0.083333 |
| 换种子 7 | 均值 0.499207（z = −0.15），std −2.53% | 统计涨落内 |

### 5.2 分箱层

| 箱中心 | 0.05 | 0.15 | 0.25 | 0.35 | 0.45 | 0.55 | 0.65 | 0.75 | 0.85 | 0.95 |
|---|---|---|---|---|---|---|---|---|---|---|
| 计数 | 10 | 35 | 92 | 127 | 209 | 218 | 180 | 85 | 38 | 6 |
| 期望 | 4.50 | 31.50 | 85.50 | 162.50 | 216.00 | 216.00 | 162.50 | 85.50 | 31.50 | 4.50 |

- 计数总和 1000，与 N 的差为 0；
- 卡方 19.335（df = 9，5% 临界 16.919，上尾 p = 0.022）：5% 水平拒绝；
- K–S 统计量 D = 0.03709（5% 临界 0.04301）：不拒绝；
- 用 Python 独立重算分箱，结果与 C 完全一致。

中心两箱 209 / 218 只差 9，约为两箱之差标准差
$\sqrt{2Np(1-p)}=\sqrt{2\times216\times0.784}=18.4$ 的 0.5σ；偏差集中在 0.05 与 0.35 两箱。
两个检验结论不一致（卡方拒绝、K–S 不拒绝），说明单次 5% 检验会误拒。
这个作业的数据本来就是有涨落的，不能拿单箱数值当精确值。

### 5.3 Lagrange 插值

10 个节点（箱中心），9 次多项式，升幂系数：

| k | c_k | k | c_k |
|---|---|---|---|
| 0 | 1.5899594574e+03 | 5 | −6.1763332610e+07 |
| 1 | −6.3261524206e+04 | 6 | 9.4466753472e+07 |
| 2 | 8.8909253712e+05 | 7 | −8.7658151455e+07 |
| 3 | −6.2284339677e+06 | 8 | 4.5184771825e+07 |
| 4 | 2.5093022678e+07 | 9 | −9.9233906526e+06 |

验证：

| 检查 | 实测 |
|---|---|
| 直接基函数在节点上的残差 | 0.000e+00 |
| 系数展开（Horner）在节点上的残差 | 1.177e−07 |
| 两种求值方式在 [0,1] 上 1001 点的最大差 | 1.643e−07 |
| 系数 vs Python 精确有理数展开 | 最大相对差 6.9e−15 |
| 节点区间内的曲线范围 | [−121.36, 223.21] |
| 外推端点 | P(0) = 1589.959，P(1) = −1339.737 |

两个必须解释的现象：

1. **单项式基的条件数**。系数本身准到 1e−15，但 \(|c_k|\sim10^8\)，在
   \(x\in[0,1]\) 上做 Horner 求值会损失约 7 位有效数字，所以残差从 0 变成
   2e−7。画曲线时用数值更稳的直接基函数形式，两者是同一个多项式。
2. **Runge 振荡**。9 次多项式在 10 个等距节点上必然在节点之间摆动，区间内
   最低到 −91.5；区间外更夸张。图上只画节点覆盖的 [0.05, 0.95]，外推不画。

### 5.4 正态拟合

模型 \(f(x)=A/(\sigma\sqrt{2\pi})e^{-(x-m)^2/(2\sigma^2)}\)，Levenberg–Marquardt，
解析雅可比，主拟合 8 次迭代收敛。

| 口径 | m | σ | A | SSE |
|---|---|---|---|---|
| **A = NΔx = 100（采用）** | **0.515569** | **0.180317** | 100 | **973.8** |
| A 自由 | 0.515529 | 0.180811 | 100.400 | 972.2 |
| 字面 A = N = 1000 | 1.508929 | 3.824021 | 1000 | 57860.6 |

- 自由幅度拟合 \(A/(N\Delta x)=1.0040\)，反过来验证了箱宽因子；
- 强行按字面 A = N 拟合，SSE 大 59 倍，m = 1.51 越出分布支撑，σ 失去意义。

残差（观测 − 拟合）：

| 箱中心 | 0.05 | 0.15 | 0.25 | 0.35 | 0.45 | 0.55 | 0.65 | 0.75 | 0.85 | 0.95 |
|---|---|---|---|---|---|---|---|---|---|---|
| 残差 | +2.11 | +6.66 | +17.21 | −18.14 | +1.91 | +0.75 | +12.44 | −10.02 | −1.62 | −6.15 |

**σ 为什么比 1/6 大？** 用精确 Irwin–Hall 期望计数（无统计涨落）做同样的
拟合，得到 σ = 0.176524（A 固定）/ 0.178039（A 自由），即比 1/6 大 5.9%。
即使样本没有涨落，高斯也要变宽：这是**高斯与 Irwin–Hall 的模型差异**
（后者的超出峰度为 −0.4、两端有界且密度为零）。本次实测的 0.180317 又比
0.176524 高 2.1%，那是 N=1000 的抽样涨落——这份样本的标准差本身偏高 4.59%。
两部分都要说清楚，拟合 σ 才能读成「有效宽度」。

残差也有系统结构：中心两箱一正一负，两端高斯明显高估（9.15 vs 3、8.68 vs 5），
说明高斯尾部比真实分布重。这正是「拟合 ≠ 插值 ≠ 精确分布」的对比。

### 5.5 稳健性检查

换种子和加大样本量，结论不变：

| 设置 | 均值 | 标准差 | 卡方 | K–S D | 拟合 σ 相对样本 std |
|---|---|---|---|---|---|
| N=1000, seed=20261024 | 0.506059（z=+1.15） | 0.174313 | 19.335 | 0.03709 | +3.44% |
| N=1000, seed=7 | 0.499207（z=−0.15） | 0.162452 | 4.177 | 0.01462 | +5.65% |
| N=100000, seed=20261024 | 0.500177（z=+0.34） | 0.166651 | 6.233 | 0.00208 | +5.99% |

N 增大到 10 万后，K–S D 从 0.024 降到 0.0018，卡方仍在临界值内；
而拟合 σ 与样本标准差之比稳定在 5.99%，与精确期望计数拟合的 5.9% 吻合，
说明这份偏差是模型差异而不是样本量不够。

|---|---|---|---|
| **1 代入恒等式** | `src/verify.c`（程序末尾自动跑） | 14 | **最强**：只把已经写进 `data/*.dat`、也就是报告里印出的数字读回来代进定义式，任何人拿计算器可复算，不依赖第二份实现 |
| 2 单元回代 | `test/selfcheck.c` | 21 | 输入输出预先已知：Irwin–Hall 密度数值积分 = 1、CDF 数值导数与解析密度差 $9.8\times10^{-10}$；$y_i\equiv1$ 时插值恒为 1；用 $(0.5,\,1/6,\,100)$ 造的精确数据喂给拟合器必须原样返回；解析雅可比 vs 中心差分 |

第 1 层的 14 项（当前全部 PASS）：

| 编号 | 恒等式 | 容差 | 代入结果 |
|---|---|---|---|
| V1 | 越界样本数（每个 x 必属一箱） | 0 | 0 |
| V2 | $\sum$ counts $= N$ | 0 | 1000 = 1000 |
| V3 | 由 samples.dat 重数的计数 == 记录计数 | 0 | 最大差 0 |
| V4 | $\sum$ expected $= N$（CDF 伸缩和） | $10^{-9}N$ | 误差 0 |
| V5 | 相邻箱首尾相接 | $10^{-12}$ | 0 |
| V6 | 文件系数代回节点 $\max\lvert P(x_i)-y_i\rvert$ | $10^{-5}$ | $1.18\times10^{-7}$ |
| V7 | 记录的 SSE == 代回重算的 SSE | $10^{-6}$ 相对 | $2.27\times10^{-13}$ |
| V8 | $\sum f(x_i)\Delta x = A = N\Delta x$（中点法） | 1% | 99.486 对 100 |
| V9 | 前 3 个样本 == 按公开递推式手算值 | $5\times10^{-13}$ | $3.78\times10^{-13}$ |
| G1–G5 | 最小二乘法方程 $J^T r = 0$（主拟合 2 项 + 自由幅度 3 项） | $10^{-6}$ | 最大 $2.6\times10^{-11}$ |

V9 用程序导出的前 12 个均匀数（`uniforms_head.dat`）重算前 4 个样本：
第 1 行 0.604850282281 必须等于 (0.917071953696 + 0.403385696810 + 0.494093196339)/3。

**检验必须会失败**，否则等于没检验。反向对照：把 `histogram.dat` 里箱 0 的计数
改大 1，第 1 层立刻报 **9 项失败**（V2、V3 直接失败，系数代回节点、SSE、
法方程随之全线崩）。判据分两类：实现级恒等式容差只为打印精度留余量；
统计级按失误率设门槛（3 倍抽样标准差、$p<10^{-3}$），不拿 5% 检验的临界值当 bug 判据——
单次 5% 检验每 20 次就会误拒一次。5% 的结果照报：本次样本卡方 19.335 拒绝、
K–S 0.03709 不拒绝。

第四项不是正确性检查，而是**稳健性**检查：`test/rng_sensitivity.c`（`test/run.sh` 第 4 步）
把同一套采样 → 分箱 → 拟合流程的随机源依次换成程序自己的 `rand()`、15 位 `rand()`
（`RAND_MAX = 32767`）与 32 位 LCG（对照），判据写死为 χ² < 25、\|均值 − 0.5\| < 3 SE、
σ ∈ [0.170, 0.190]、自由幅度 A ∈ [99, 103]。三种随机源全部 PASS，
说明「σ 的有效宽度 ~0.1765」和 `A = NΔx` 都不依赖发生器；固定种子的用途是让同一份 `data/` 与报告表格一一对应。
负向对照：把发生器换成常数 0.5，该项 FAIL、退出码 1。

**这套核对的边界**：代入恒等式证明「实现自洽」，不证明「模型合适」——
字面 $A=N$ 的拟合同样满足 G1–G5（它是自己那个 SSE 的极小点），但 SSE 是主拟合的
59.42 倍。模型合不合适要靠对精确 Irwin–Hall 计数的拟合来判断。

## 7. 四个坑

1. **A = N 还是 NΔx**：题目公式是密度，分箱纵轴是计数；Δx = 0.1，差 10 倍。
   字面拟合会把 σ 拉到 3.96，得到一条几乎水平的「拟合」。
2. **单项式基的条件数**：系数可以准到 1e−15，但代回求值可能只剩 1e−7。
   记录参数是一回事，稳定求值是另一回事。
3. **高次插值的 Runge 振荡**：9 次多项式穿过 10 个带噪声的点，节点之间会甩出去；
   它适合展示「插值不是拟合」，不适合拿来当分布。
4. **高斯只是近似**：真实分布是 Irwin–Hall，拟合 σ 的有效宽度约 0.1765（比 1/6 大 5.9%）；
   要检验分布本身，应该用第 2 步的精确 CDF / 卡方 / K–S。
