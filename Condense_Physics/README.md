# 晶胞立体图 · SC / BCC / FCC / Wigner–Seitz

固体物理作业用的小网页：用可交互的 3D 图展示 **简立方 (SC)**、**体心立方 (BCC)**、
**面心立方 (FCC)** 三种惯用晶胞，以及它们对应的 **Wigner–Seitz (WS) 原胞**。

- SC 的 WS 原胞 = **立方体**（6 个正方形面）
- BCC 的 WS 原胞 = **截角八面体**（14 面：6 正方形 + 8 正六边形）
- FCC 的 WS 原胞 = **菱形十二面体**（12 个全等菱形面）

WS 原胞不是画死的，而是由「取一个格点 → 向近邻/次近邻连线 → 作中垂面 → 围出最小多面体」
这套定义**实时计算**出来的（求所有三平面交点，再回收各个面）。

## 怎么打开

最简单：直接双击 **`crystal-cells.html`**。它是单文件版本，three.js 已经内联进去，
不需要联网、不需要开服务器。

也可以打开 `index.html`（配合同目录的 `app.js`）。

## 操作

- 鼠标左键拖拽旋转，滚轮缩放，右键平移。
- 左侧切换 SC / BCC / FCC；开关原子、晶胞棱框、最近邻键、WS 原胞、近邻方向。
- 把「原子半径」拉到 1.00 就是刚球接触，可以直接看出堆积率。
- 「近邻方向（构造）」会画出中心格点到最近邻/次近邻壳层的连线，直观看到中垂面是怎么切出 WS 原胞的。
- 「扩展晶格点云」把周围晶格点画出来，营造"无限晶格"的感觉（范围可调）。
- 「WS 原胞平铺」在每个共面的近邻格点上再放一个 WS 胞，能直接看到它们面贴面、无缝填满空间。
- 「坐标轴 a/b/c」显示晶轴方向。

### URL 参数（方便直接分享某个视图）

`crystal-cells.html?s=BCC&tile=1&ext=0&axes=1`

| 参数 | 含义 |
| --- | --- |
| `s` | `SC` / `BCC` / `FCC` |
| `atoms` `cell` `bonds` `ws` `nn` | `1` 开 / `0` 关 |
| `ext` `axes` `tile` | 扩展晶格点云 / 坐标轴 / WS 平铺，`1` 开 `0` 关 |
| `range` | 扩展晶格点云范围（1.5–4，单位 a） |
| `r` | 原子半径比例（0.25–1） |
| `rot` | `1` 自动旋转 |

重新打包：

```bash

```

```bash

```

## 设计说明

- **WS 原胞是算出来的，不是画出来的**：由近邻/次近邻格点作中垂面（半空间），
  求三平面交点得到多面体顶点，再按平面回收各个面。所以尺寸严格对应晶格常数 a，
  且信息面板里的 V/E/F 与几何同源。
- 扩展晶格点云、坐标轴 a/b/c、雾效这几点借鉴了 `Qwen_version.html`；
  但它把 WS 顶点写死、BCC/FCC 尺寸偏大（分别约 1.82× 和 2×），这里没有沿用。
- 额外加了 **WS 原胞平铺**：只在「与中心胞共面的近邻格点」上再放 WS 胞
  （SC 6 个、BCC 8+6 个、FCC 12 个），能直观看到面贴面、无缝填满空间。

## 顺手复习一下（作业内容）

| | SC 简立方 | BCC 体心立方 | FCC 面心立方 |
| --- | --- | --- | --- |
| 每惯用晶胞原子数 | 8×1/8 = **1** | 8×1/8 + 1 = **2** | 8×1/8 + 6×1/2 = **4** |
| 配位数 CN | **6** | **8** | **12** |
| 最近邻方向 | &lt;100&gt; | 体对角线 &lt;111&gt; | 面对角线 &lt;110&gt; |
| 最近邻距离 | a | (√3/2)a ≈ 0.866a | (√2/2)a ≈ 0.707a |
| 刚球半径 | a/2 | (√3/4)a | (√2/4)a |
| 堆积率 | π/6 ≈ **52.36%** | √3π/8 ≈ **68.02%** | √2π/6 ≈ **74.05%** |
| WS 原胞 | 立方体（6 面） | 截角八面体（14 面） | 菱形十二面体（12 面） |
| 典型材料 | α-Po | Fe、Cr、W、Mo、Na | Cu、Al、Au、Ag、Ni |

几个容易记混的点：

- WS 原胞是**体积最小的原胞**，只含 1 个格点，体积 = a³/n，而且能无缝填满空间。
- BCC 的 WS 原胞是**截角八面体**，FCC 的是**菱形十二面体**，别记反。
- BCC 的六边形面来自 8 个最近邻（体对角线），正方形面来自 6 个次近邻（沿 &lt;100&gt;）。
