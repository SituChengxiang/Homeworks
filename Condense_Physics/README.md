# 固体物理 · 晶胞可视化（三个单文件网页）

## 1. `crystal-cells.html` — SC / BCC / FCC 与 Wigner–Seitz 原胞

用可交互的 3D 图展示 **简立方 (SC)**、**体心立方 (BCC)**、**面心立方 (FCC)**
三种惯用晶胞，以及它们对应的 **Wigner–Seitz (WS) 原胞**，并带一套
**「画晶胞的过程」分步演示**（格点 → 晶轴 → 晶胞 → 基元 → 份额 → 配位数 → 中垂面 → WS 原胞）。

- SC 的 WS 原胞 = **立方体**（6 个正方形面）
- BCC 的 WS 原胞 = **截角八面体**（14 面：6 正方形 + 8 正六边形）
- FCC 的 WS 原胞 = **菱形十二面体**（12 个全等菱形面）

WS 原胞不是画死的，而是由「取一个格点 → 向近邻/次近邻连线 → 作中垂面 → 围出最小多面体」
这套定义**实时计算**出来的（求所有三平面交点，再回收各个面）。

## 2. `diamond-zincblende.html` — 金刚石 / 闪锌矿 ZnS 的体对角线平移

演示 **金刚石型结构 = 两套面心立方沿体对角线 [111] 错开 ¼**：拖动滑杆或点「▶ 体对角线平移动画」，
看第二套 FCC 从 0 滑到 ¼ 个对角线长，滑到位的那一刻键长正好是 √3a/4，
每个原子获得 4 个近邻、键角 109.47° 的正四面体配位。材料可切 **C（金刚石）/ Si / ZnS（闪锌矿）**，
原子半径按真实共价、离子半径比例画（数据见文末表格）。

## 3. `hcp-close-packed.html` — 六方密堆积 HCP 与堆积率推导

解决"堆积率到底怎么算"这件事：分步演示从**一个密置层**开始（每个球贴 6 个，a = 2R），
到**第二层只能填一半的三角形空隙**，再到 ABAB 堆叠、六方棱晶胞、份额裁剪数原子
（12×1/6 + 2×1/2 + 3 = 6），然后画出**正四面体**推出轴比 c/a = √(8/3) = 1.633，
最后右侧面板把 APF 逐行代入：

```
APF = n·(4/3)πR³ / [(3√3/2)a²c]，n = 6，a = 2R，c = √(8/3)a  ⟹  π/(3√2) = √2π/6 ≈ 74.05%
```

74.05% 与 FCC 是同一个数（同一个 π/(3√2)，只是写法不同）。
可切换**理想轴比 / Mg / Zn / Cd / Ti / Be** 或拖 c/a 滑杆：偏离理想值时，
层内与层间不能同时相切，最先接触的那组决定球半径，堆积率就掉到 74% 以下
（Mg 73.6%、Be 71.2%、Ti 72.0%、Zn 65.1%、Cd 64.2%）。

## 怎么打开

最简单：直接双击 `crystal-cells.html`、`diamond-zincblende.html` 或 `hcp-close-packed.html`。
三者都是单文件版本，three.js 已经内联进去，不需要联网、不需要开服务器。

开发版页面是 `index.html` + `app.js`、`diamond.html` + `diamond-app.js`、`hcp.html` + `hcp-app.js`。

## 操作 · `crystal-cells.html`

### 分步演示：把「画晶胞的过程」走一遍

打开左侧**「分步演示」**开关，屏幕下方会跟着步骤讲解，从「一个格点」一路搭到 WS 原胞
（SC 16 步，BCC / FCC 17 步——多的那一步是补体心 / 面心原子）：

| 步 | 内容 |
| --- | --- |
| 1 | 任选一个格点——把原子抽象成空间点阵（布拉维格子） |
| 2 | 取出三条晶轴 a / b / c |
| 3 | 沿晶轴平移一个周期，划出 8 个顶角格点与晶胞棱框 |
| 4 | 格点 + 基元 = 晶体结构：先摆顶角原子 |
| 5 | 顶角原子被 8 个胞共用 → 裁出 1/8 份额（虚影是分给邻胞的部分） |
| 6 | BCC / FCC：补上体心 / 面心原子，数出每胞原子数 n（2 / 4）；SC：n = 1 |
| 7 | 把原子放回完整的样子 |
| 8 | 最近邻与配位数 CN（6 / 8 / 12） |
| 9 | 刚球接触，直接看堆积率（52.36% / 68.02% / 74.05%）——球是**连续涨到**接触尺寸的 |
| 10 | 把原子收小，退回"只看格点"的眼睛（进 WS 之前的过渡） |
| 11 | Wigner–Seitz：从格点向近邻、次近邻连线 |
| 12 | **画出垂直平分面**（半透明圆片，过连线中点、与连线垂直） |
| 13 | 中垂面围出 WS 原胞 |
| 14 | WS 原胞平铺，面贴面无缝填满空间 |
| 15 | 把惯用晶胞盖回去对比（体积比 n∶1） |
| 16 | 两种取法摆在一起 → 收尾只留晶胞 + WS 原胞 |

- 用「← 上一步 / 下一步 →」或底下的步骤编号按钮跳转；键盘 **←/→** 切步骤、**空格** 播放/暂停。
- 「▶ 自动播放」每 5 秒推进一次，适合课堂放映。
- 演示模式下图层由步骤决定，手动开关会暂时变灰；关掉开关即回到自由查看。
- **只有这一步新出现的图层才做生长/淡入**，已经在那儿的东西保持不动；半径变化用补间过渡。
  所以按"下一步"是往前推进，而不是把整幅画重播一遍。
- 节奏由校验脚本守着：`test/verify.js` 会把每一步"实际画出什么"归一化成集合
  （`atoms` 与 `share` 视为同一批原子，只是切不切），相邻两步必须**至少变 1 项、至多变 4 项**——
  原地不动的死步骤和一次换掉大半张图的跨步都会报错。

### 自由查看

- 鼠标左键拖拽旋转，滚轮缩放，右键平移。
- 左侧切换 SC / BCC / FCC；开关原子、晶胞棱框、最近邻键、WS 原胞、近邻方向、WS 中垂面。
- 把「原子半径」拉到 1.00 就是刚球接触，可以直接看出堆积率。
- 「近邻方向（构造）」会画出中心格点到最近邻/次近邻壳层的连线，直观看到中垂面是怎么切出 WS 原胞的。
- 「WS 中垂面」把每个近邻连线的中垂面画成半透明圆片，单独看这一步的裁剪关系。
- 「扩展晶格点云」把周围晶格点画出来，营造"无限晶格"的感觉（范围可调）。
- 「WS 原胞平铺」在每个共面的近邻格点上再放一个 WS 胞，能直接看到它们面贴面、无缝填满空间。
- 「坐标轴 a/b/c」显示晶轴方向。

## 操作 · `diamond-zincblende.html`

- **平移量滑杆** `t`：0 → ½ a，实时显示位移长度 |Δ| = √3·t·a（换算成 Å），右下角的讲解跟着 t 换。
  `t = 0` 两套 FCC 完全重合；`t = ¼` 就是金刚石 / 闪锌矿；`t = ½` 两套 FCC 互补、合成一个
  间距 a/2 的简单立方（配位从 4 变 6），正好是课堂上的反面教材。
- **▶ 体对角线平移动画**：把第二套 FCC 沿 [111] 缓动推到 ¼ 并停住；已经在 ¼ 时再点一次会从头重演。
  「归零」「跳到 ¼」可单独控制；键盘 **↑/↓** 触发同样动画，**←/→** 微调（按住 Shift 更细）。
- **沿 [111] 看**：一键把相机转到体对角线方向，四面体配位看得最清楚。
- 图层开关：亚点阵 A（顶点 + 面心）、亚点阵 B（体内 4 个）、晶胞棱框、最近邻键（四面体）、
  体对角线参考 + 平移矢量、扩展晶格点云、**份额视图**（顶点 1/8、面心 1/2、体内 1）、自动旋转。
- 材料：**C（金刚石）/ Si（晶体硅）/ ZnS（闪锌矿）**。原子按真实共价半径、离子半径比例绘制，
  右侧面板给出 a、键长 √3a/4、同种最近邻 a/√2、每胞原子数、配位数与键角 109.47°、
  按真实半径算的堆积率，以及两套亚点阵的分数坐标。

## 操作 · `hcp-close-packed.html`

| 步 | 内容 |
| --- | --- |
| 1 | 密置层 A：一个球周围正好贴 6 个，同层最近邻 a = 2R |
| 2 | 三角形空隙分尖朝上/朝下两种，各占一半 |
| 3 | 第二层 B 只能坐其中一种，本胞内落下 3 个整原子 |
| 4 | 第三层回到与第一层对齐的位置 → ABAB（若落 C 就是 FCC 的 ABCABC） |
| 5 | 围出六方棱柱晶胞（底面边长 a、高 c；它是 3 个初基胞） |
| 6 | 份额裁剪：12×1/6 + 2×1/2 + 3×1 = **6** 个原子 |
| 7 | 正四面体推出 **c/a = √(8/3) = 1.633**（层间距 = √(2/3)a） |
| 8 | 配位数 12：同层 6 + 上层 3 + 下层 3 |
| 9 | 把相切的键连起来（四面体骨架） |
| 10 | 堆积率 = 6 个球体积 / 棱柱体积 = π/(3√2) ≈ 74.05% |
| 11 | 真实金属：c/a 偏离理想值 → 掉到 74% 以下 |

相邻两步的实际画面差异由 `test/verify.js` 限制在 **2–4 项**（不会原地不动，也不会一步换掉大半张图），
并且只有新出现的图层才做生长动画。

- **c/a 滑杆**（1.45–1.95）+ 材料预设（理想 / Mg / Zn / Cd / Ti / Be）：右侧面板实时代入
  a、c、层间球心距离 √(a²/3+c²/4)、刚球半径 R、6 个球体积、棱柱体积、APF。
- 「沿 c 轴看」= 俯视密置层的六角网格；「侧看堆叠」= 从侧面看 ABAB 层序。
- 图层开关：三层原子、三角形空隙、棱柱棱框、份额裁剪、最近邻键、配位数高亮、
  正四面体推导线、层名/份额标签、扩展点阵、自动旋转。
- 键盘 ←/→ 切步骤、空格播放暂停；演示模式下手动画灰。

## 导出视频（离线，无需联网）

不方便提交网页时，可以用无头 Chrome 把三个页面**逐帧渲染**成视频，再用 ffmpeg 合成：

```bash
./build.sh                       # 先打包（渲染用的是单文件成品）
node tools/make-video.js         # 三条片子全渲
node tools/make-video.js hcp --gif
node tools/make-video.js --smoke 8        # 只均匀抽 8 帧，检查管线通不通
```

依赖：Google Chrome（默认 `/opt/google/chrome-unstable/chrome`，可用环境变量 `CHROME=` 覆盖）
和 `ffmpeg`。全程不需要网络，也不需要 npm 依赖——Node 自带的 `fetch` + `WebSocket` 直接讲 CDP。

输出在 `videos/`（当前已渲好的一版）：

| 文件 | 内容 | 时长 | 大小 |
| --- | --- | --- | --- |
| `videos/crystal.mp4` | SC → BCC → FCC 各走一遍分步演示（16 + 17 + 17 步） | 25 s @ 1280×720 | 2.7 MB |
| `videos/diamond.mp4` | 三种材料各演一次 t：0 → ¼ → ½（两套 FCC 滑开、再合并成简单立方） | 13 s | 1.3 MB |
| `videos/hcp.mp4` | HCP 的 11 步 + 轴比从 1.633 拖到 1.88 | 11 s | 0.8 MB |

同名 `.gif` 也在（8.1 / 4.2 / 2.6 MB）——**交作业建议用 mp4**，gif 体积大且只有 12 fps。

实现要点：

- 页面加 `?film=1` 进入**摄制模式**（`src/view.js` 的 `installFilmAPI`）：隐藏左右侧栏，
  只留 3D 画面和画布上的步骤浮层；关掉阻尼与自动旋转，`window.__film.set({…})`
  一帧一个确定画面，截图不含时间噪声。
- **自动取景**：按当前可见图层的包围盒算焦点和距离，但跳过背景点云
  （`userData.noFrame`）——否则点云把包围盒撑大，晶胞会缩成画面中间一个小点。
- **棱框/键用细圆柱画**（`tubeEdges`）：WebGL 里 `LineSegments` 的 linewidth 恒为 1 像素，
  在视频里被球完全挡住；六方棱框还额外设 `depthTest = false`，因为它本来就穿过相切球的球心。
- 分镜（每步机位、停留帧数、补间曲线）都在 `tools/make-video.js` 顶部，想改节奏直接改那里。

## 设计说明

### 性能：三个页面共用的渲染策略

- **自动旋转速度**在 `src/view.js` 的 `AUTO_ROTATE_SPEED`（三个页面共用），按 OrbitControls 的约定是 `60 / speed` 秒一圈，默认 1.0 ≈ 一分钟一圈。`startLoop` 会把 `deltaTime` 传给 `controls.update()`，所以 60 Hz 和 144 Hz 屏上转得一样快（不传就会按「每帧固定角度」自转，高刷屏上快 2～2.4 倍）。
- **按需出图**：`startLoop` 只在「场景真的变了」时才 `render`，空闲时不占 GPU，
  笔记本不会因为这个页面一直转风扇。拖动/缩放/自动旋转/生长动画都会正确触发重绘。
- **纯计算结果缓存**（`src/geometry.js`）：`latticePoints / nearestDistance / computeWS /
  atomsFor / uniqueEdges / wsStats` 全是纯函数，按参数缓存。
  实测一次交互的几何计算：**冷启动 1.3–6 ms → 缓存命中 0.0004–0.0007 ms**
  （`./test/bench.sh` 可复现；FCC 的 WS 要枚举 C(20,3) 个三平面交点，是最贵的一步）。
- **GPU 资源缓存**（`src/view.js`）：几何体只用单位球/单位圆/单位方框 + 缩放，
  材质与文字贴图按 key 复用；重建场景时**不再新建任何 geometry / material / texture**。
  校验脚本会直接扫描页面源码，出现 `new THREE.SphereGeometry(...)` 这类写法就报错。
- **图层对象缓存**：`crystal-cells.html` 的每个图层按「结构类型 + 参数」缓存整组对象，
  切换开关只是把现成的 Group 挂回场景；`diamond-zincblende.html` 更进一步——
  所有对象一次建好，平移只改坐标、点云矩阵、键缓冲（固定容量 + `setDrawRange`）和箭头长度。
- **快速路径**：拖动半径滑杆时直接缩放现成的球，不重建场景图；
  因此这些图层的缓存键里刻意**不含半径**，避免"缓存对象被改过尺寸"的不一致。

### 物理与几何

- **WS 原胞是算出来的，不是画出来的**：由近邻/次近邻格点作中垂面（半空间），
  求三平面交点得到多面体顶点，再按平面回收各个面。所以尺寸严格对应晶格常数 a，
  且信息面板里的 V/E/F 与几何同源。
- 扩展晶格点云、坐标轴 a/b/c、雾效用于营造"无限晶格"的纵深感。
- **份额原子是裁出来的，不是画个数字**：顶角/面心原子用三维裁剪面
  （过原子球心、平行于晶胞面的平面）真的切成本胞内的 1/8、1/2，虚影是被邻胞占去的部分。
  所以「8×1/8 + 6×1/2 = 4」是能直接看见的，`test/verify.js` 还会校验这些份额之和等于 n。
- **分步演示是数据驱动的**：`src/steps.js` 里每步只是一组图层开关加讲解文案，
  `main.js` 的 `rebuild()` 负责把图层画出来。校验脚本会检查图层名是否都被 `rebuild()` 认出来，
  避免新增图层时拼错导致那一步静默失效。
- 额外加了 **WS 原胞平铺**：只在「与中心胞共面的近邻格点」上再放 WS 胞
  （SC 6 个、BCC 8+6 个、FCC 12 个），能直观看到面贴面、无缝填满空间。
- **金刚石页把「平移」做成了可拖的物理量**：位移写成分数 t（单位 a），
  于是 |Δ| = √3·t·a、键长 = √3a/4 这些关系是屏幕上实时算出来的数，不是硬编码的文字。
  顺便还能看到两个极端：`t = 0` 两套 FCC 重合，`t = ½` 它们合成一个简单立方（间距 a/2，六配位）。
- **半径用真实数值换算**：显示尺寸 = (r_真实 / a) × A，所以金刚球的 2r 正好等于键长、
  ZnS 里 Zn²⁺ 只是空隙里的小球。经验半径表有百分之几的偏差，`test/verify.js` 里按 3% 容差校验。

### 六方密堆积 HCP

| | 理想 HCP | Mg | Ti | Be | Zn | Cd |
| --- | --- | --- | --- | --- | --- | --- |
| 堆叠顺序 | ABAB | ABAB | ABAB | ABAB | ABAB | ABAB |
| a（同层最近邻） | — | 3.209 Å | 2.951 Å | 2.286 Å | 2.665 Å | 2.979 Å |
| c | — | 5.211 Å | 4.686 Å | 3.584 Å | 4.947 Å | 5.610 Å |
| c/a | **1.6330** | 1.624 | 1.588 | 1.568 | 1.856 | 1.883 |
| 每棱柱胞原子数 | **6** | 6 | 6 | 6 | 6 | 6 |
| 配位数 | **12**（同层 6 + 上 3 + 下 3） | 12 | 12 | 12 | 12 | 12 |
| 堆积率 | **74.05%** | 73.6% | 72.0% | 71.2% | 65.1% | 64.2% |

堆积率的推导链条（页面第 6–9 步就是按这个顺序画的）：

1. **底面密置层**：一个球周围正好贴 6 个 → 同层最近邻 = a = 2R。
2. **数原子**：12 个顶角各被 6 个棱柱共用（同层 3 家 × 上下 2 层）→ 1/6；
   上下底面中心各被 2 个棱柱共用 → 1/2；中间层 3 个整颗在胞内 → 1。
   `12×(1/6) + 2×(1/2) + 3×1 = 6`。
3. **轴比**：同层 3 个相切球心 + 层间 1 个球心 = 棱长 a 的正四面体。
   底面三角形中心到顶点是 `a/√3`，故层间距 `= √(a² − a²/3) = √(2/3)·a`；
   一个周期里有两层间距 → `c = 2√(2/3)a` → **c/a = √(8/3) = 1.633**。
4. **体积**：底面正六边形 `= 6·(√3/4)a² = (3√3/2)a²`，棱柱 `= (3√3/2)a²c`
   `= (3√3/2)·√(8/3)·a³ = 3√2·a³`。
5. **堆积率**：`APF = 6·(4/3)π(a/2)³ ⁄ (3√2 a³) = π⁄(3√2) = √2π⁄6 ≈ 74.05%`
   —— 和 FCC 是**同一个数**（π/(3√2) 上下同乘 √2 就是 √2π/6）。

HCP 与 FCC 的对照：

- 两者每层都是密置层、配位数都是 12、理想堆积率都是 74.05%，**差别只在层序**：
  HCP 是 ABAB…，FCC 是 ABCABC…（第三层落在剩下那批空隙上就变成 FCC）。
  所以"六方"不等于堆得松，"立方"也不等于堆得紧。
- 74.05% 只在**理想轴比**取到。c/a 偏长（Zn、Cd）层间留缝，偏扁（Be、Ti）层间先接触；
  刚球半径由更近的那组决定 `R = min(a, √(a²/3+c²/4))/2`，于是 APF 掉到 74% 以下。
- 六方棱柱**不是初基胞**：含 3 个初基胞、6 个原子；初基胞 2 个原子、体积 `(√3/2)a²c`。

几个容易记混的点：

- WS 原胞是**体积最小的原胞**，只含 1 个格点，体积 = a³/n，而且能无缝填满空间。
- BCC 的 WS 原胞是**截角八面体**，FCC 的是**菱形十二面体**，别记反。
- BCC 的六边形面来自 8 个最近邻（体对角线），正方形面来自 6 个次近邻（沿 &lt;100&gt;）。
- 金刚石结构**不是**「FCC 加个体心」：它是两套 FCC 沿体对角线错开 **¼**（不是 ½），
  所以每个原子只有 4 个近邻、成正四面体，配位数比 FCC 低得多，堆积率只有约 34%。
- 闪锌矿和金刚石**原子位置完全一样**，只是两套亚点阵换成不同元素（Zn/S）；
  所以岩盐结构（NaCl，六配位）和闪锌矿（四配位）别混——差别就在位移是 ½&lt;100&gt; 还是 ¼&lt;111&gt;。
