# 分模块提问脚本（逐条可直接复制发送）

> 用法：新建一个干净的对话，把下面 13 条 prompt **一条一条**发出去，
> 每发一条等模型写完再发下一条。每轮截一张图，就是这个文件对应的
> 「与大语言模型的交互过程」，比一份总结式的记录更像真实过程。
>
> 每条后面的「这一步拿到什么」是给你自己看的目标答案，用来检查模型有没有写偏；
> 「对应文件」是本仓库里最终落点。
>
> 前置：Linux + GCC 16，`sh build.sh` 能编译；报告需要 Typst 0.15 与
> `bash ../../scripts/typst-local-packages.sh` 注册模板。

---

## 第 1 轮：题目 + 技术路线

```
计算物理作业，严格 C89（-std=c89 -pedantic-errors -Wall -Wextra -Werror），
CLion/CMake，Linux。和前两次作业一样的要求：分模块写、C 只算数并导出 data/*.dat、
Python 只读文件画图不参与计算、每步写完先编译跑出一个实测的验证表再停下等我确认。

题目：一根各向同性铁棍，长 l = 0.1 m。初始时中间长 0.01 m 的一段温度 u = 100 ℃，
其余 0 ℃。两种边界条件：(1) 两端接触温度恒为 0 ℃ 的理想导热体；(2) 周期边界。
求两种条件下棍上各点温度随时间的变化。要求 (a) Δx = 0.1 cm，Δt 与收敛条件自设；
(b) 用生成式 AI 完成；(c) 记录交流过程；(d) 画两种边界下 10/20/30 s 与完全收敛后的曲线；
(e) Δx = 0.2 cm 重复一遍。

先别写代码。这道题有哪些数是我必须先定下来、否则后面全部图形都会变的？
```

**这一步拿到什么**：模型应该指出两个决定性参数——题目没给铁的热扩散率 α（并算出
α 取不同值时基模衰减时间 τ = l²/(π²α) 差多少、为什么无量纲 α=1 会让 10/20/30 s
三条曲线全部重合而失去区分度），以及数值格式做到哪一层（只显式 FTCS，还是加
Crank–Nicolson 对照）。还要它给出目录结构与分步计划。

**对应文件**：本仓库的 10 步计划与 `heat_diffusion/` 骨架。

## 第 2 轮：题目参数与材料层

```
纯铁，α 取 2.3e-5 m^2/s，格式做 FTCS + Crank-Nicolson 对照。开始第 1 步。

写两个模块：一个把题目给定的量集中定义（几何、温度、默认 Δx/Δt、要画的时刻、
收敛容差），别的模块不许再写死这些数字；一个把「铁」翻译成方程里的 α，
并派生出 Fourier 数 r、显式格式的稳定上限、最低阶模的衰减时间。

α 不许写成一个孤零零的魔数——用导热率、密度、比热独立算一遍 k/(ρc) 做交叉核对。
写完编译运行，把实测数字列出来。
```

**这一步拿到什么**：`include/config.h` + `material.h/.c`。实测 k/(ρc) = 2.2798e-5，
与表值 2.3e-5 差 **+0.887%**；τ_Dirichlet = 44.052689 s，τ_周期 = 11.013172 s，比值 4.0；
10/20/30 s 分别是 0.227/0.454/0.681 个 τ（说明 30 s 远未收敛，曲线会有区分度）；
Δx=0.001 时 dt_max = 0.0217391304 s，取 dt=0.01 得 r = 0.23。

**对应文件**：`include/config.h`、`include/material.h`、`src/material.c`

## 第 3 轮：初始温度场——用有限体积口径

```
下一步：网格与初始温度场。

初值不许按「哪个节点落在 [0.045, 0.055] 里就设成 100」来写，那样总热量会错。
按控制体平均：节点 i 代表 [x_i - Δx/2, x_i + Δx/2]，温度取初始分布在这个控制体上的
平均值；周期边界要处理跨界回绕。再配一个总热量、平均温度、对称性偏差的统计函数。

同时把「闭区间打点」那种写法也实现一份，作为负向对照，实测它差多少。
写完编译运行，给验证表。
```

**这一步拿到什么**：`grid.h/.c`。实测 FV 热量在两种口径下都是 1.000000000000 ℃·m、
周期均值 10.000000000000 ℃、对称性偏差 6.892e−13；naive 在 Δx=0.001 时给 **11 个**
100 ℃ 节点、热量 1.1、周期均值 **11 ℃**（多算 10%，因为闭区间里 11 个节点对 10 个单元），
在 Δx=0.002 时碰巧对。**还要它主动测出浮点端点问题**：C 里 `HOT_LO=(0.1-0.01)/2` =
0.045000000000000005274 而 `x[45]` = 0.044999999999999998335，不带容差时左端点被判在
区间外，naive 只数到 10 个节点、热量碰巧等于 1.0 但初值不再对称。

**对应文件**：`include/grid.h`、`src/grid.c`

## 第 4 轮：显式 FTCS

```
下一步：显式 FTCS 推进器，两种边界都要。

先把稳定性讲清楚再写代码——把格式改写成凸组合，说明 r ≤ 1/2 这个条件从哪来。
scratch 缓冲不能省，说明为什么原地更新是错的。推进要能精确落在 10/20/30 s 上，
末步不足一个 Δt 时按剩余时间缩短。

跑完之后：(1) 逐步盯着周期均值守恒、Dirichlet 热量单调、最大最小值不越出初值范围、
对称性保持；(2) 把 r 依次取 0.23 / 0.5 / 0.575 / 0.69，看稳定与发散的分界，
并且**发散速率要等于最高频模的理论放大因子**，光「炸了」不算验证。
```

**这一步拿到什么**：`solver.h/.c`。实测 3000 步周期均值漂移 1.243e−14、热量上升 0 次、
极值违反 0 次；r=0.575 第 115 步越过 1e12、r=0.69 第 52 步，纯模态实测每步
1.2994325444 / 1.7593190533 与理论 |G| 对到 10 位小数。
**模型应该主动改方法**：物理初值是多模叠加，k=98 与 k=99 的 |G| 只差 0.13%，
干涉让增长率高估约 1%（1.2875 对 1.2994），换成精确特征向量才能把判据收紧到 1e−9。
另外 `isfinite` 是 C99 的，要严格 C89 得换成 `v != v` 与 `v - v != 0`。

**对应文件**：`include/solver.h`、`src/solver.c`

## 第 5 轮：离散特征值的精确核对

```
再加一层验证：sin(q x_i) 和 cos(q x_i) 是差分拉普拉斯的精确特征向量，
代入得 G = 1 - 4r sin²(q Δx/2)。把单个模态跑 m 步，实测 u/u₀ 应该严格等于 G^m。

低频模和最高频模都要测。另外把每个模态的离散 G 和连续解每步的 exp(-α q² Δt) 比一下，
这个比值就是空间离散误差——告诉我它在低频和高频各是多少。
```

**这一步拿到什么**：实测/理论相对差 5.5e−14 / 1.7e−11 / 2.8e−15。
离散/连续：Dirichlet k=1 差 **−7.09e−7 %**，周期 k=1 差 −1.14e−5 %，
**Dirichlet k=99 差 −25.774%**（最高频模被网格多阻尼四分之一）。
模型还应发现高频模跑 1000 步会 `G^m` 下溢成 0 变成 0/0，需要按 |G|^m ≥ 1e−6 限制步数。
这条是 (e) 问「Δx 加倍再画一遍」的意义所在。

**对应文件**：`src/main.c` 的 `report_mode`

## 第 6 轮：Fourier 级数解析解

```
下一步：分离变量法的解析解，当数值解的标尺。只做数学，不碰网格。

Dirichlet 用 b_k = (400/(kπ)) sin(kπ/2) sin(kπw/(2l)) 的正弦级数，
周期用 10 + Σ A_k cos(2kπx/l) 的余弦级数。

系数不许只给解析式——再用复合 Simpson 对初值做数值投影算一遍，两者必须对上。
级数本身也要检查：t=0 时在跳跃点应该收敛到跳变中值 50，峰顶应该有 Gibbs 过冲。
```

**这一步拿到什么**：`analytic.h/.c`。系数解析式 vs Simpson 投影差 1.8e−15 ~ 2.2e−13。
**这一步应该抓到一个 bug**：如果模型第一版把周期系数写成 (200/(kπ))[sin(kπhi/l)−sin(kπlo/l)]，
即 sin 里漏了因子 2、前置因子多乘 2，两个错误会在**偶数 k 上恰好抵消**，
表格看起来只是「系数错位一格」——Simpson 列是对的，靠它才能发现。
跳跃点误差比 4.0000（1/K 律），Gibbs 外推 **8.948985%** 对理论 8.948987%。

**对应文件**：`include/analytic.h`、`src/analytic.c`

## 第 7 轮：Gibbs 的采样陷阱

```
Gibbs 过冲那个数，你是固定步长扫描峰顶的吗？过冲峰到间断点的距离按 l/K 收缩，
K 大了固定步长会漏掉峰。改成窗口随 K 自适应，并且别拿单个 K 的读数去卡容差——
S(K) = S∞ + c/K，取两个 K 做外推再和理论比。理论值也别凭记忆，数值积分算 Si(π)。
```

**这一步拿到什么**：模型应该承认固定 2e−6 步长扫 K=2×10⁵ 时读出「过冲 −0.002%」
是采样伪影，改成窗口 8l/K、点数固定；用 K=10⁴ 与 4×10⁴ 做 Richardson 外推；
数值积分得 Si(π) = 1.851937051982466，过冲分数 = Si(π)/π − 1/2 = **8.948987%**
（并承认原先凭印象写的 8.9490 差在第五位）。

**对应文件**：`src/main.c` 的 `series_t0_peak` / `report_analytic_series`

## 第 8 轮：收敛阶怎么读才干净

```
现在把数值解和解析解逐点比，并且读出格式的收敛阶：固定 Δx 细化 Δt 应该一阶，
固定 r 细化 Δx 应该二阶。

但先想清楚：固定 Δx 细化 Δt，真的能读出干净的一阶吗？FTCS 的稳定性把 Δt 和 Δx² 绑在
一起，时间误差和空间误差谁占主导？如果读不出来，换个能读出来的测法。
```

**这一步拿到什么**：模型应该推出 **时间误差/空间误差 = 12r ≤ 6** 这个与模态、网格无关
的关系，说明固定 Δx 细化 Δt 必然撞上空间地板（实测比值 2.297 / 2.849 / **1.202**），
然后改用**同网格 Δt 与 Δt/2 两个数值解相减**（空间误差相同自动抵消），
得到干净的 2.0010 / 2.0005 / 2.0002。空间二阶用纯模 + r 固定给 4.0007 / 4.0002。

**对应文件**：`src/main.c` 的 `ftcs_time_diff` / `report_convergence_order`

## 第 9 轮：误差到底由谁主导

```
方波初值算出来的总误差，别直接归给格式。它里面还有一项「离散初值 vs 精确方波」的
表示误差。把 FV 初值当分段常数函数，解析地算出它自己的 Fourier 系数，
这样总误差就能拆成「格式误差 + 表示误差」两块，每一块都能单独代数字检查。

拆出来看看：Δx=0.002 和 Δx=0.001 各自哪一块占主导？为什么？
```

**这一步拿到什么**：Δx=0.002 时**表示误差恒等于零**（1.78e−14）——不是抵消，
而是高温段边界正好落在**单元边界**上，FV 重构与精确方波是同一个函数；
Δx=0.001 时边界落在**节点中心**，多出两个 50 ℃ 半格，表示误差 4.92e−3
占总误差 **84.7%**。所以 (e) 问的两档网格误差构成根本不同。
另外格式误差随 Δt **变号**（r=0.46 时 −6.81e−3，r=0.0575 时 +4.79e−3），
因为时间项过阻尼、空间项欠阻尼，r≈0.23 接近互相抵消点。

**对应文件**：`src/main.c` 的 `fv_coeff_dirichlet` / `report_error_decomposition`

## 第 10 轮：Crank–Nicolson 对照

```
下一步：Crank-Nicolson 对照模块。二阶时间，隐式。

Dirichlet 下左端是三对角，用 Thomas 追赶法；周期下是循环三对角，
用 Sherman-Morrison 降回三对角（写清 u、v 怎么取、A' 的对角首尾为什么要修正）。

然后测两件事：(1) 它在大 r（5、50、500）下发不发散；(2) 它保不保离散极值原理。
我预期「无条件稳定」不等于「无条件好」，把差别量出来。
```

**这一步拿到什么**：`crank.h/.c`。r=50 用 5 步、r=500 用 **1 步**走完 10 s，都不发散，
但 max u 变成 39.24 / 55.21（真值 18.43），min u 打到 **−3.57 / −34.33 ℃**——
右端矩阵对角权重 1−r 变负。**CN 换来稳定性，丢掉单调性**，FTCS 在 r≤1/2 时两样都保。
离散特征值 G = (1−2rs²)/(1+2rs²)，实测/理论相对差 1.5e−13 / 3.2e−11 / 2.0e−13；
最高频模上两个格式**朝相反方向错**（连续要求 0.1081，FTCS 给 0.0802 多阻尼，
CN 给 0.3700 少阻尼）。

**注意**：如果模型写了「同 Δt 下 CN 必然更准」的判据，应该被数据否证——
CN 的绝对误差对 Δt 几乎不动（已被 Δx² 地板钉住），而 FTCS 在 r=0.23 恰好踩在
反号抵消点上，有时反而更小。判据要改成比**纯时间误差**（CN 赢 1960 倍）。

**对应文件**：`include/crank.h`、`src/crank.c`

## 第 11 轮：收敛判据与完整调度

```
下一步：收敛判据 + 跑完 2 种 Δx × 2 种边界的全部组合 + 导出交付数据。

主判据用 max|u − u∞| ≤ ε，u∞ 不许猜，要从边界条件推出来。
再实现一条很多人爱用的「逐 step 变化量小于阈值」判据，并且定量测出它比主判据松多少。
（我猜它松的倍数和某个时间尺度有关，你算算是什么。）

导出：剖面文件（10/20/30 s + 收敛后）、完整时空演化 u(x_i,t_n)、判据扫描表、汇总表。
参数一律写成 key=value 的注释头，让后面的核对程序按 key 取，不靠行序。
```

**这一步拿到什么**：`converge.h/.c` + `export.h/.c`。u∞ = 0（Dirichlet）/ 10（周期）。
四种组合的 t_conv = 740.38 / 184.94 / 740.57 / 185.14 s，与单指数预测 τ·ln(A/ε)
最大相对差 **0.0955%**。副判据松 **τ/Δt = 4405** 倍：ε_step=1e−6 时在 370.77 s 就停手
（只有正确时刻的一半），那时残差 4.4040e−3，与预测 ε_step·τ/Δt = 4.4053e−3 吻合到 0.1%。
扫描用「从后往前找最后一次超阈值」而不是首次穿越。

**对应文件**：`include/converge.h`、`src/converge.c`、`include/export.h`、`src/export.c`

## 第 12 轮：代入式核对 + 它必须能失败

```
最后写核对层：把 data/ 里已经写出的数字读回来，代进各自的定义式检查。
这是最强的一层——任何人拿计算器能照同一批数复算，不依赖第二份实现。

至少要有：初值定义式、总热量、端点条件、极值原理、对称性、收敛判据自洽，
以及把导出的剖面直接代进 FTCS 差分格式和离散的热量收支等式。

写完做篡改测试：改一个交付数字，看它会不会失败。
```

**这一步拿到什么**：`verify.h/.c`，56 项。最强的是 V9/V10——不重算任何东西，
只把文件里的数代进差分格式（残差 1.67e−15）与**离散**守恒律
Σ(u_i^{n+1}−u_i^n) = −r(u₁ⁿ+u_{n−1}ⁿ)（差 6.1e−15）。

**关键**：篡改测试第一版会报「0 项失败」——因为程序先重算覆盖了被改的文件。
必须加一个 **只核对不重算**的入口 `--verify-only`，加上之后改 1 ℃ 报 4 项 FAIL、
改 1e−6 报 2 项 FAIL。跨文件比对要用**相对**容差（演化文件只存 10 位有效数字，
值约 10 ℃ 时往返误差本来就是 5e−10 绝对量）。

**对应文件**：`include/verify.h`、`src/verify.c`

## 第 13 轮：交付图、三层验证、单文件版

```
出图：题目 (d)(e) 的四张（两种 Δx × 两种边界，各含 10/20/30 s 与收敛后曲线 + 初值虚线），
再加两种 Δx 同图对照与逐点差、完整时空热力图、FTCS 失稳与 CN 负温度、误差预算。
图例里承诺的每条曲线，用像素统计验证它真的画出来了——不要只写完就交。

然后补齐验证：C 单元自检（期望答案手工算出，CN 用稠密高斯消元独立解做交叉）、
Python 独立实现交叉（CN 走完整矩阵 LU）、稳健性对照（4 种 Δx × 2 种格式，
结论是否只依赖物理量）、单文件版逐字节等价。全部串进 test/run.sh，
并把负向对照做成其中一层，不是可选项。
```

**这一步拿到什么**：8 张图 + 49 项像素核对 + 40 项自检 + 40 项 Python 交叉 +
22 项稳健性 + 22 个文件逐字节一致 + 3 处负向对照，合计 301 项。

**这一轮最可能暴露的三件事**：

1. **单文件版编不过**——如果 `value_is_finite` 在 `solver.c` 和 `crank.c` 各有一份同名
   static 函数，分开编译没事，并成一个翻译单元就是重定义。抽成 `util.h/.c`。
2. **naive 初值的错是双向的**——扫到 Δx=0.004 时 naive 给热量 **0.8，少算 20%**。
   正确结论是 |超额| ≤ Δx/w，符号取决于边界落在哪，不能说「只在细网格暴露」。
3. **单元自检会抓到模型自己的手算错误**（不是代码错误）：回绕重叠当成 0.001（实际 0.002）、
   常值场的均值当成 10（实际 100）、FTCS 在 r=1/2 的 Nyquist 模 G 当成 0（实际 −1，
   归零在 r=1/4）、CN 的分母写成 4r（实际 2r）。

**对应文件**：`plot.py`、`plot_final.py`、`test/`、`make_single_source.py`

## 附：几条通用的追问

| 场景 | 值得追一句 |
|---|---|
