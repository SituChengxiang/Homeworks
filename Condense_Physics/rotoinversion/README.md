# 作业 A · 反轴 n̄ 与等效点系

黄昆《固体物理》"晶体的对称性"：`3̄ = 3 + i`、`4̄ = 4 + i`，那么 `6̄ = ?`
→ **`6̄ = 3/m`**（真 3 次轴 + 垂直镜面，C3h；里面根本没有 6 次操作）。

交付物是 **`rotoinversion.html`**（约 510 KB，three.js 已内联，双击即开、不联网）。

## 这页怎么讲这件事

左栏 3D、右栏 **上下圈展开图**（教材俯视图缩成右下角的角标）。论证全靠展开图，
因为它把"有没有水平镜面"变成一个**数得出来的量**：

> 高度换成半径（上圈 z>0、下圈 z<0），方位角原样保留 —— 于是 6 个点就是 6 个点，
> 而"下圈有几个点落在上圈的径向线上"直接等于"有没有 m⊥"。

```
       俯视图        展开图 上/下     下圈落在径向上的点数
1̄    2 点 → 2 处     1 / 1            0    → 没有 m⊥，只有穿心的 i
2̄    2 点 → 1 处     1 / 1            1    → 上下互为镜像 → m⊥
3̄    6 点 → 6 处     3 / 3            0    → 3 + i
4̄    4 点 → 4 处     2 / 2            0    → 既无 i 也无 m⊥，所以独立
6̄    6 点 → 3 处     3 / 3            3    → 全部对齐 → 3/m
```

只看教材俯视图会被骗：$\bar{3}$ 的六个点每隔 60° 均匀排开，**长得就像一个 6 次对称图案**；
$\bar{6}$ 的上下成对两点又会重合，让人误读成"只有 3 个点"。所以展开图当主角、俯视图当对照，
每个点还额外标出 z 的数值（各家教材半填朝向不一致，数字不会错）。

## 操作

翻页在字幕条两端（下一步还会露出下一步的关键词），底下是分段进度轨，点哪段跳哪段。
键盘/翻页笔：`→` `空格` 下一步、`←` 上一步、`1 2 3 4 6` 直接跳到讲那根反轴的一步、
`L` 图层抽屉、`D` 数据抽屉、`F` 纯净模式、`Esc` 取消选中。
点 3D 里的等效点、展开图里的点、数据表里的行，三处同时高亮。

八步：定义 → `1̄` → `2̄` → `3̄` → `4̄` → **`6̄ = ?`** → 一步一步施加 → 为什么只有这五种。

## 文件

```
index.html        页面外壳（布局与控件样式，尺寸全部来自 design/tokens.css 的 --u）
src/steps.js      八步脚本：图层 + 文案 + 要把状态调到哪
src/render3d.js   3D 图层：轴与记号、定义路径、基元、等效点、配对线、镜面片、中心
src/main.js       状态 → (3D, 2D, 字幕, 进度轨, 数据表) 的单向装配
test/verify.js    反轴群论事实 + 展开图统计量 + 分步脚本 + 页面 id + 单文件产物
build.sh          Vite 构建 → 内联成单文件
```

数学不在这里：`../lib/` 是矩阵与反轴群的内核，`../design/` 是符号层与设计系统。
构建与校验：`./rotoinversion/build.sh`、`./rotoinversion/test/run.sh`。

## 一条硬规矩

画面与文案上出现的每个数字（阶、点数、落成几处、对齐几个）都由 `lib/` 现算，
`test/verify.js` 里还有一条自检：**判定为"有 m⊥"却数不出全对齐，直接抛错** ——
不许图和结论各说各话。
