# 一维热传导作业：两种边界条件下的铁棍温度演化（C89 + FTCS/CN + Fourier 级数）

## 1. 题目

一根各向同性铁棍，长 `l = 0.1 m`。**初始**时中间长 `w = 0.01 m` 的一段温度
`u = 100 ℃`，其余 `0 ℃`。两种边界条件：

1. **Dirichlet**：两端接触温度恒为 0 ℃ 的理想导热体；
2. **周期边界**（PBC）：两端首尾相接。

求两种条件下棍上各点温度随时间的变化。

| 要求 | 本项目的落实 |
|---|---|
| (a) Δx = 0.1 cm，Δt 与收敛条件自设 | Δt = 0.01 s（r = 0.23 ≤ 1/2）；主判据 max\|u−u∞\| ≤ 1e−6 ℃，另配一条逐 step 判据并实测它松多少 |
| (b) 用生成式 AI 完成 | Qoder 桌面端，分 13 轮 |
| (c) 提交完整交流记录 | 报告附录（`doc/interaction.typ`，由 `doc/make_interaction.py` 从 Qoder 会话存档生成）+ `doc/大模型交互记录.md` + `doc/分模块提问脚本.md` |
| (d) 画 10/20/30 s 与完全收敛后的曲线 | `data/fig_d1_*.png`、`data/fig_d2_*.png` |
| (e) Δx = 0.2 cm 重复 | `data/fig_e1_*.png`、`data/fig_e2_*.png` |

英文版还多要求一句 "**the full time-varying temperature evolution at all discrete
points**"，所以另外导出完整 `u(x_i, t_n)` 并画时空图（`data/fig_evolution.png`）。

英文版 "**Initially** ... uniform **initial temperature**" 把 100 ℃ 钉成**初值**而不是
维持源。这点必须说清：若是维持源，Dirichlet 的稳态会是中间 100 ℃ 的分段直线，
周期边界根本不收敛。本项目按初值做，两种终态分别是 0 ℃ 与 10 ℃。

## 2. 物理建模

各向同性 ⇒ α 是标量，截面方向无变化，方程退化成一维

```
∂u/∂t = α ∂²u/∂x² ,  0 < x < l
```

### α 的取值与交叉核对

题目只说「铁棍子」，没给 α。它直接决定 10/20/30 s 三张曲线的形状。

```
采用（手册表值）   α = 2.3e-5 m²/s   （= 23 mm²/s）
独立核对           k/(ρ·cp) = 80.2 / (7870 × 447) = 2.2798e-5 m²/s
实测相对偏差        +0.887%
```

表值来源：维基百科「热扩散率」条目的材料表格（本机直连该页 DNS 解析失败，
数值取自搜索索引到的表格内容，因此同时给出 k/(ρc) 这条可自查的换算作为约束）。

派生的时间尺度（最低阶模衰减到 1/e）：

```
τ_Dirichlet = l²/(π²α)  = 44.052689 s     → 10/20/30 s 是 0.227/0.454/0.681 个 τ
τ_周期      = l²/(4π²α) = 11.013172 s     → 比 Dirichlet 快 4 倍
```

所以 **30 s 时 Dirichlet 远未收敛**，三条中间曲线必然各不相同。若把 α 取成无量纲 1，
τ ≈ 0.001 s，三个时刻全部早已收敛成同一条线，(d) 的要求会退化——这是选 α 时必须先算的。

### 两种边界与各自的终态

| 边界 | 离散处理 | 终态 u∞ | 依据 |
|---|---|---|---|
| Dirichlet | `u[0] = u[n] = 0` 每步钉回 | **0 ℃** | 热量从两端漏光 |
| 周期 | 只有 i=0..n−1 是未知量，i=n 与 i=0 同一点，邻点模 n 回绕 | **10 ℃** | Σu_i·Δx 是精确守恒量，u∞ = 初值平均 |

10 ℃ 不是拟合参数，是边界的推论，并且被当成收敛判据的基准。

### 解析解（分离变量法）

```
Dirichlet:  u = Σ b_k sin(kπx/l) e^(−α(kπ/l)²t),  b_k = (400/(kπ)) sin(kπ/2) sin(kπw/(2l))
周期:       u = 10 + Σ A_k cos(2kπx/l) e^(−α(2kπ/l)²t),  A_k = (200/(kπ)) (−1)^k sin(kπw/l)
```

Dirichlet 偶数项恒零、周期的正弦项恒零，都是初值关于棍中点对称的后果。

## 4. 构建与运行

严格 C89：

```sh
sh build.sh          # gcc -std=c89 -pedantic-errors -Wall -Wextra -Werror -O2
```

`-Werror` 是必须的：有一轮 `printf` 里漏转义一个 `%`，gcc 只给 warning，程序照编照跑，
那个格式串会读一个未定义参数。加了 `-Werror`，「零警告」这句话才由编译器保证而不是由脚本打印。

一条龙（编译 → 计算并导出 → 出图 → 像素核对）：

```sh
sh run.sh
```

分步：

```sh
./build/heat_diffusion data              # 全部计算 + 导出 + 128 项核对
./build/heat_diffusion --verify-only data # 不重算，只核对 data 里现有的数字
python3 plot_final.py data               # 8 张图
sh test/run.sh                           # 七层验证，约 20 秒
```

C89 只依赖标准库与 `-lm`；Python 端只要 numpy / matplotlib / pillow，不需要 scipy。

### 单文件版（演示 / 交作业用）

```sh
python3 make_single_source.py
gcc -std=c89 -pedantic-errors -Wall -Wextra -Werror -O2 heat_diffusion_single.c -o hd -lm
./hd data
```

它不是另写一份实现，而是由脚本把 `include/` 与 `src/` 按依赖顺序拼成一个翻译单元。
`test/run.sh` 第 5 步重新生成、编译、跑出来，和 `data/` 的 **22 个文件逐字节比对**。
顺带它还是个**静态作用域检查器**：`value_is_finite` 原先在 `solver.c` 和 `crank.c`
各有一份同名 static 函数，分开编译相安无事，并成一个单元立刻重定义——于是抽出了 `util.h/.c`。

## 5. 验证结果

以下数字全部来自 `data/`，`sh test/run.sh` 可复现。

### 5.1 初值口径（表 3）

| Δx | FV 热量 | naive 热量 | naive 超额 | 上界 Δx/w | FV 初值的构成 | naive 节点数 |
|---|---|---|---|---|---|---|
| 0.0005 | 1.000000000000 | 1.050000000000 | **+5%** | 5% | 19 个 100 ℃ + 2 个 50 ℃ | 21 |
| 0.001 | 1.000000000000 | 1.100000000000 | **+10%** | 10% | 9 个 100 ℃ + 2 个 50 ℃ | 11 |
| 0.002 | 1.000000000000 | 1.000000000000 | 0% | 20% | 5 个 100 ℃，**没有半格** | 5 |
| 0.004 | 1.000000000000 | 0.800000000000 | **−20%** | 40% | 2 个 100 ℃ + 2 个 25 ℃ | 2 |

naive（闭区间打点）的错是**双向**的：节点数只能是 ⌊w/Δx⌋ 或它加 1，所以
|超额| ≤ Δx/w，符号取决于边界落在哪。Δx=0.001 时 11 个节点对 10 个单元、
周期均值被顶成 11 ℃；Δx=0.004 时只数到 2 个节点（0.048 与 0.052）、终态被压到 8 ℃。
FV 口径在四档网格上热量都是 1.000000000000001，部分格的取值随 Δx 变（0.0005 与 0.001
给 50 ℃，0.004 给 25 ℃，0.002 干脆没有半格）。
端点判断还必须带几何容差：实测 C 里 `HOT_LO` = 0.045000000000000005274 而
`x[45]` = 0.044999999999999998335，不带容差时左端点被判在区间外。

### 5.6 误差分解与收敛阶（表 11、表 12、表 13）

| Δx | 格式误差 | 表示误差 | 总误差 | 表示占比 |
|---|---|---|---|---|
| 0.0020 | 3.5537e−03 | **1.7764e−14** | 3.5537e−03 | 0.0% |

**负向对照是第七层的一部分，不是可选项**（`test/run.sh` 第 7 步自动跑）：

```
(a) 篡改 u_t0 一格 50 -> 51        → 4 项失败（V1、V2、V6、V12）
(b) sensitivity --sabotage 置零初值 → 14 项如预期失败

```

`./build/heat_diffusion data`，程序先重算覆盖、再去「读回核对」，于是 0 项失败——
代入式核对形同虚设。加了 `--verify-only` 之后同一处篡改立刻报 4 项失败。

## 7. 五个坑

1. **初值口径**：闭区间打点的误差双向，|超额| ≤ Δx/w。Δx=0.1 cm 多算 10%（终态 11 ℃），
   Δx=0.4 cm 少算 20%（终态 8 ℃）。端点判断还必须带几何容差，否则连「错成 11 个节点」
   都数不齐——热量碰巧对，但初值不再对称。
2. **收敛判据**：「逐 step 变化量小于阈值」在慢衰减问题上会提前一半时间停手，
   松 τ/Δt = 4404 倍。必须问「离物理终态还差多少」，而 u∞ 由边界条件推出来。
3. **无条件稳定 ≠ 无条件好**：CN 在 r=500 一步走完 10 s、不发散，但峰值错成 55.2 ℃
   并打出 −34.3 ℃ 负温度。稳定与单调是两个独立性质。
4. **固定 Δx 细化 Δt 读不出时间阶**：稳定性把 Δt 和 Δx² 绑死，时间误差最多只有
   空间误差 12r ≤ 6 倍，必然撞上空间地板。要读阶就用「同网格两种 Δt 相减」。
5. **Gibbs 峰要自适应扫描**：峰到间断点的距离按 l/K 收缩，固定步长会把峰整个漏掉
   （实测读出「过冲 −0.002%」）。而且别拿单档 K 的读数卡容差，要做 1/K 外推。
